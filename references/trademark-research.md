# Trademark Research & Nice Classification Guide

This guide assists video game developers in conducting preliminary trademark searches across major intellectual property registries.

---

## 1. Important Legal Disclaimer

> [!WARNING]
> This skill and its generated links provide **preliminary factual search guidance only**, not formal legal clearance or legal advice. A clear search result does not guarantee that a mark is free to use or register. Common law rights, unregistered marks, foreign priority filings, and cross-class disputes can affect trademark availability. Always engage a certified trademark attorney or solicitor before public brand launch or significant commercial investment.

## 2. Relevant Nice Classification Classes for Video Games

When searching trademark databases, examine the following International (Nice) Classes:

### Class 9 — Core Software & Hardware Goods
- Downloadable video game software and computer programs.
- Mobile game applications (iOS, Android).
- Recorded video game software on physical media (cartridges, discs).
- Virtual reality (VR) headsets, controllers, and game peripherals.
- Downloadable virtual game goods and avatars.

### Class 28 — Physical Games, Toys & Arcade Machines
- Dedicated video game consoles and arcade game machines.
- Action figures, board games, and physical toys based on game franchises.
- Standalone gaming handheld devices.

### Class 41 — Entertainment & Online Gaming Services
- Provision of online non-downloadable computer games.
- Multiplayer game network services and cloud gaming.
- Organizing eSports tournaments, competitions, and gaming events.
- Production and streaming of video game gameplay and entertainment shows.

### Class 42 — SaaS, Game Engine & Technology Services
- Video game development services.
- Software-as-a-service (SaaS) hosting game servers.
- Game engine licensing and technical cloud infrastructure.

## 3. Database Search Procedures

### WIPO Global Brand Database
- **Portal:** [branddb.wipo.int](https://branddb.wipo.int/)
- **Coverage:** Madrid System international registrations + participating national registries.
- **Workflow:** The skill automatically generates a pre-filled JSON query URL. Click the link to view matching wordmarks across all jurisdictions. Filter results by Nice classes 9, 28, and 41.

### USPTO Trademark Search (United States)
- **Portal:** [tmsearch.uspto.gov](https://tmsearch.uspto.gov/)
- **Workflow:**
  1. Open the portal.
  2. Select "Word Mark" search.
  3. Enter the proposed game title.
  4. Review "Live" vs "Dead" registrations.
  5. Check Goods & Services for Class 009 or Class 041.

### EUIPO eSearch plus (European Union)
- **Portal:** [euipo.europa.eu/eSearch/](https://euipo.europa.eu/eSearch/)
- **Workflow:**
  1. Navigate to basic search.
  2. Enter the title.
  3. Filter by Nice Class 9 and 41.
  4. Note any active European Union Trade Marks (EUTMs) in force.

### TMview (Multi-Jurisdiction Aggregator)
- **Portal:** [tmdn.org/tmview/](https://www.tmdn.org/tmview/)
- **Workflow:**
  1. Enter title in the search box.
  2. Check status indicators (Registered, Filed, Expired).
  3. Inspect national offices relevant to your key target markets.

### TÜRKPATENT (Turkey)
- **Portal:** [turkpatent.gov.tr](https://www.turkpatent.gov.tr)
- **Workflow:**
  1. Navigate to Marka Araştırma / Online İşlemler.
  2. Search exact mark text.
  3. Examine Sınıf 9, 28, 41.
  4. Cross-reference with WIPO Global Brand DB for Madrid System registrations designating Turkey (TR).
